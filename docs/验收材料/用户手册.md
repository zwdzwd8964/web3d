## 快捷键

改快捷键请改 `packages/editor/src/shortcuts/table.ts` 里的 `SHORTCUTS`，然后跑：

```bash
UPDATE_DOCS=1 pnpm -F @w3/editor test docs-blocks
```

在输入框、文本域里，下面每一条都**不生效**——那时候键盘属于那个输入框。

<!-- GENERATED:shortcuts -->
### 文件

| 键位 | 作用 |
|---|---|
| `Ctrl+S` | 立即保存（编辑后也会自动保存） |

### 编辑

| 键位 | 作用 |
|---|---|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` 或 `Ctrl+Shift+Z` | 重做 |
| `Ctrl+C` | 复制选中的对象 |
| `Ctrl+V` | 粘贴（整棵子树一次撤销） |
| `Ctrl+D` | 就地复制一份并选中它 |
| `Delete` 或 `Backspace` | 删除选中的对象（先问一句） |
| `F2` | 重命名选中的对象 |

### 选择

| 键位 | 作用 |
|---|---|
| `Ctrl+A` | 全选 |
| `Escape` | 取消选择（面板开着时先关面板） |
| `Ctrl+F` | 定位到层级树的搜索框 |

### 帮助

| 键位 | 作用 |
|---|---|
| `?` 或 `F1` | 打开 / 关闭这张快捷键速查表 |
